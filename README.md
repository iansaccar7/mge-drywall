# MGE Drywall Forros Zona Leste

Site estático responsivo, com animações de scroll e galeria horizontal no desktop. Sem dependências de runtime ou etapa de build.

## Executar localmente

Na pasta do projeto, execute `python3 -m http.server 8000` e abra http://localhost:8000.

## Publicar

No GitHub Pages, selecione a branch `main` e a pasta `/ (root)`. Os recursos usam caminhos relativos e as fontes são locais.

## Arquivos

- `index.html`: conteúdo, serviços, galeria e formulário.
- `style.css`: identidade visual e layout responsivo.
- `script.js`: formulário que prepara a mensagem para o WhatsApp.
- `motion.css` e `motion.js`: animações de entrada e galeria; respeitam movimento reduzido e mantêm conteúdo acessível sem JavaScript.
- `dmsans-OFL.txt`: licença das fontes DM Sans.
